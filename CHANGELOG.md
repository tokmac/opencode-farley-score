# Changelog

## 1.0.0 (2026-06-12)

### Initial Release

- `/farley-score` — Slash command for autonomous test quality analysis
- `/farley-score-coach` — Slash command for interactive Socratic coaching
- `farley_score` tool — Auto-invoked test analysis with Farley Index
- `farley_coach` tool — Auto-invoked coaching with 10 built-in exercises
- Pure JavaScript implementation — no Python dependency
- 5 language support: Python, Java, JavaScript/TypeScript, C#, Go
- Signal detection: tautologies, mocks, sleep, I/O, reflection
- 10 coaching exercises: trivial-tautology, mock-tautology, mega-test, shared-state, sleep, implementation-coupling, over-specified, framework-test, cryptic-name
